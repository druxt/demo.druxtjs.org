# Changelog

Changes to this site are recorded here. The format is
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- The Druxt repository standard: committed git hooks, Conventional Commits
  checked by hook and over the merge request range, an attribution check, Vale
  prose linting, cspell, markdownlint, yamllint, actionlint, knip, a
  production dependency audit and a private-host lint.
- A GitLab pipeline and a GitHub workflow running the same checks, with
  gitleaks secret scanning and a canary that proves the scanner still detects.
- Docker-free provisioning of the Drupal backend in `drupal/.devtools`, from
  the committed configuration and Tome content, on SQLite.
- Unit tests with an enforced coverage floor, and Playwright end-to-end and
  visual tests against the generated site, with baselines regenerated by a
  manual pipeline job.
- A dev container for VS Code, Codespaces and DevPod.
- Brand styling, analytics and share metadata on the front page.

### Changed

- The front end installs with npm. The unused `yarn.lock` is gone.
- The GitHub workflow runs on every pull request, whatever it targets.

### Removed

- Gitpod. The dev container replaces it.
